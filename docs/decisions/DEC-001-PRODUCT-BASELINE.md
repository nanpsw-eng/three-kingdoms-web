# DEC-001 — Product Baseline

## Status
APPROVED — 2026-10-01

## Decision
Build a modernized classic Three Kingdoms army RPG optimized for mobile portrait web/PWA. Use Tap-to-Move, optional virtual d-pad, Visible Encounter, five-person parties, Smart Command, troop-based combat, fixed-identity general growth and region-based Semi-open exploration.

## Explicit exclusions for initial product
No belt-scroll action baseline, no default random encounters, no global level scaling, no gacha rarity, no duplicate-general limit break and no MMO/PvP/guild features in MVP.
