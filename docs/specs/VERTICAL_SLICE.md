# VERTICAL SLICE CONTENT SPEC v0.1

## Goal
Validate the complete core loop in 20–30 minutes before scaling content production.

## Flow
`탁현 → 탁군 남부 평야 → 백수촌 → 백수림 → 황건 전초기지 → 북부 관문 Boss → 관문 점령`

## Teaching order
1. Tap-to-Move
2. NPC interaction
3. Visible Encounter
4. Smart Command
5. Troop concept
6. Unit matchup
7. Recruitment
8. Tactics
9. Formation
10. Boss telegraph

## Key events
- Start with Liu Bei, Guan Yu, Zhang Fei.
- Recruit Jian Yong in Baishui village.
- Forest side path can reveal an optional recruit.
- Unlock three formations before the final gate.
- Capture a Yellow Turban outpost to demonstrate world-state mutation and recovery point.
- Final 5-unit boss force uses a commander + power fighter + common units.
- Victory changes ownership/flags, reduces nearby enemies and reveals the next region.

## P0 systems
Semi-open field, Tap-to-Move, visible encounters, five-person battle, Smart Command, troop combat, tactics, formations, recruitment, party, equipment, quest, boss, autosave and world-state change.

## Exit gate
Do not expand to full Yellow Turban MVP until exploration usability, battle input, troop understanding, recruitment reward, strategic choices and conquest payoff are validated.
